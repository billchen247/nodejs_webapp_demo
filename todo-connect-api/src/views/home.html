Todo Connect API

The same tiny REST API as todo-node-api, but built on top of Connect — a minimalist middleware framework (and Express's ancestor).

Requests flow through a pipeline of middleware: cors → body → router → notFound → errorHandler. Each middleware is a plain function of (req, res, next) and lives in its own file under src/middleware/.

Endpoints

MethodPathDescription
GET /api/todos List every todo (optional ?completed=true|false)
GET /api/todos/:id Fetch a single todo
POST /api/todos Create a todo (body: {"title":"..."})
PUT /api/todos/:id Update a todo
DELETE /api/todos/:id Delete a todo

Live todos

Loaded straight from GET /api/todos using the browser's built-in fetch(). Refresh after changing data/todos.json or hitting the API.
